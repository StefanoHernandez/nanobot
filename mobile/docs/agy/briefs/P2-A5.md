## Context
Claude's core is done. Read these; do not edit them:
- `mobile/src/extras/voice.ts`:
  - `voiceAvailable(settings)`, where `settings` comes from `session.get("/api/settings")`
  - `useVoiceInput(onTranscript?)` returns `{ state: "idle"|"recording"|"transcribing"|"error", elapsedMs, error, start(), stop(): Promise<string|null>, cancel() }`. `onTranscript` also fires on the 120 s auto-stop.

  - `loadSubagentThread(session, key, taskId): Promise<UIMessage[]>`, read-only
  - Read `SubagentTaskSnapshot` in `mobile/vendor/nanobot/webui/src/lib/types.ts` ~69-89. Statuses: `queued|running|stopping|done|incomplete|error|cancelled|interrupted`.
- `mobile/src/screens/thread/MessageList.tsx` renders messages; reuse it for the read-only subagent thread.

## What to build
**Files:**
- `mobile/src/screens/thread/VoiceButton.tsx`
- Modify `Composer.tsx` to add the VoiceButton:
  - Show it when `voiceAvailable(settings)` is true. Load settings once per session and cache them in component state; on failure, hide the button.
  - It sits right of the input. When the draft is empty and nothing is running, it takes the send button's place; otherwise it sits next to it.
- `mobile/src/screens/thread/SubagentsSheet.tsx`, plus a header badge button in `ThreadScreen.tsx`. That button is the only addition to the header.
- `mobile/app/chat/[key]/subagent/[id].tsx` and `mobile/src/screens/thread/SubagentThreadScreen.tsx`
- i18n keys `voice.*` and `subagents.*` in it and en
- Test: `mobile/test/screens/voice-subagents.test.tsx`

**VoiceButton:**
- Idle shows a `microphone` icon. Tapping calls `start()`.
- Recording shows a red pulsing dot, `m:ss` elapsed, a stop button (calls `stop()`) and a cancel button (calls `cancel()`).
- Transcribing shows a spinner.
- The transcript, whether returned by `stop()` or delivered by `onTranscript`, is **appended to the draft**, with a space if the draft isn't empty. It is **never sent automatically.**
- When `error` becomes non-null, show a toast with the i18n text; `transcription: <detail>` shows the detail.

**Subagents:**
- **Badge:** in the thread header, when `subagentsAvailable(session, key)` and `tasks.length > 0`. It is an `IconButton` (`robot-outline`) with a small count of tasks whose status is `queued`, `running` or `stopping`. Tapping opens the sheet.
- **SubagentsSheet:** lists the tasks, newest first. Each row shows the label/title from the snapshot fields, a status chip colored by status from theme tokens, and the elapsed or finished time if available.
  - A running or queued task has a **Cancel** button, behind a confirm `Dialog`, that calls `cancel(id)`.
  - Tapping a row navigates to `/chat/<enc key>/subagent/<enc id>`.
- **SubagentThreadScreen:**
  - Header: back, plus the task title and status.
  - Body: `loadSubagentThread`, then `MessageList`, read-only, with no composer.
  - Loading spinner. On error, inline text plus Retry.
