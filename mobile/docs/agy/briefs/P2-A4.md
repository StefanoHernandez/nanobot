## Context
In the nanobot WebUI, typing `@` in the composer lets you mention another **session** (a chat that has a `handle`), a **CLI app**, or an **MCP preset**. The message text keeps `@name`, and the structured lists go along with the message. Exact shapes are in `.superpowers/sdd/phase2-vendor-map.md` sections 6 and 7; read them.

The data comes from these sources (via `useSession().session.get<T>(path)`):
- **Sessions:** `useChats` (`mobile/src/state/chatsStore.ts`) `chats: ChatSummary[]`. Only rows with `handle: {id, name}` are mentionable.
- **CLI apps:** `GET /api/settings/cli-apps?installed_only=1` returns `CliAppsPayload { apps: CliAppInfo[] }`. Keep apps where `installed` is true.
- **MCP presets:** `GET /api/settings/mcp-presets` returns `McpPresetsPayload { presets: McpPresetInfo[] }`. Keep a preset when `source !== "agent-plugin" && (preset.enabled ?? (preset.installed && preset.configured))`.

The types are in `mobile/vendor/nanobot/webui/src/lib/types.ts`: `SessionMention` ~201, `CliAppInfo` ~1053, `McpPresetInfo` ~1229, and `OutboundCliAppMention`/`OutboundMcpPresetMention` ~1670-1688. Read them.

Sending goes through `useThreadSlice(key).send(text, { sessionMentions, cliApps, mcpPresets })`.

## What to build
**Files:**
- `mobile/src/screens/thread/mentions.ts` (pure):
  - `sessionCandidates(chats)`
  - `filterCandidates(all, query)`
  - `toSessionMention(chat)` returns `{ id: handle.id, name: handle.name, session_key: chat.key, title: chat.title ?? "" }`
  - `toCliAppMention(app)` and `toMcpPresetMention(preset)`, which build the outbound shapes exactly as in vendor-map section 7. Set `logo_url` and `brand_color` to `?? null`.
  - `pruneMentions(text, picked)`, which drops picked items whose `@name` token is no longer in the text.
- `mobile/src/screens/thread/MentionMenu.tsx`: a popup above the input, like the slash menu, with three sections "Chat", "App", "MCP" and rows of at least 48 dp.
- Modify `Composer.tsx`:
  - The menu opens when the token at the cursor starts with `@` at a word start (the start of the input or after whitespace). Filter by the text after `@`, case-insensitive.
  - Selecting replaces the token with `@name ` and records the item.
  - Keep the picked items in component state, pruned with `pruneMentions` on every text change.
  - On send, pass the three lists, only those non-empty, and clear them after `send` returns true.
  - Session mentions are capped at 8: a ninth shows a toast and is not added. Dedupe by `session_key`.
  - Load the CLI apps and MCP presets once per session, failing silently.
- i18n keys `mentions.*` in it and en.
- Test: `mobile/test/screens/mentions.test.tsx`

## Tests (write first, see them fail, then implement)
- `toSessionMention` gives an id starting with `handle_`, the name, the session_key and the title.
- The MCP filter excludes `source: "agent-plugin"` and includes `{installed:true, configured:true}` with `enabled` undefined.
- In the composer, typing `"hey @co"` shows candidates that match `co` (a chat `coder`, an app `codex`). Selecting `coder` sets the draft to `"hey @coder "`.
- After deleting `@coder` from the text, send passes no `sessionMentions`.
- A ninth session mention is refused with a toast.
- Send with one of each passes all three lists to `send`.
