## Context
Server task `P7-S1` exposes the Multi-Bot & Kanban API:
- `GET /api/ext/kanban?board_id=<id>` → `{ boards: KanbanBoard[], active_board: KanbanBoard, bots: BotPersona[], tasks: KanbanTask[], links: TaskLink[], messages: BoardMessage[] }`
- `GET /api/ext/kanban/task?id=<task_id>` → `{ task: KanbanTask, parents: KanbanTask[], children: KanbanTask[], runs: TaskRun[], messages: BoardMessage[] }`
- Mutations via `useSettings().mutate`:
  - `"kanban.bot.save"` (`{ id?, name, icon, role_prompt, model_preset?, max_concurrent? }`)
  - `"kanban.bot.delete"` (`{ id }`)
  - `"kanban.board.create"` (`{ title, description? }`)
  - `"kanban.task.save"` (`{ id?, board_id, title, description, status?, priority?, assignee_bot_id?, reviewer_bot_id?, workspace_mode?, recurrence_expr?, parent_ids? }`)
  - `"kanban.task.move"` (`{ id, status }`)
  - `"kanban.task.delete"` (`{ id }`)
  - `"kanban.task.review"` (`{ id, approved, feedback? }`)
  - `"kanban.message.post"` (`{ board_id, task_id?, content }`)

We want to add **"Kanban & Bot"** to the Ecosystem hub (`mobile/app/ecosystem/index.tsx` → `/ecosystem/kanban`), with 3 tabs:
1. **Board:** board selector chip row + horizontal scrollable status columns (`triage`, `todo`, `ready`, `running`, `review`, `blocked`, `done`) with task cards showing title, priority badge, assigned bot icon/name, and dependency count; tapping a card opens `KanbanTaskSheet`; "+" button opens a sheet to create a task.
2. **Chat di Gruppo (Board Chat):** group chat over the active board where the user can message the bots, tap quick `@bot` mention chips to wake a specific bot (`@coder`, `@reviewer`, etc.), and see bot replies with their persona icon and name.
3. **Bot (Personas):** list of configured bot personas (`icon`, `name`, `role_prompt`, `model_preset`, `max_concurrent`), with "+" / tap to create or edit a bot persona in `BotPersonaSheet`, and delete behind a destructive confirm `Dialog`.

### 1. `mobile/src/ecosystem/kanban.ts`
Define types (`BotPersona`, `KanbanBoard`, `KanbanTask`, `TaskStatus`, `TaskPriority`, `TaskRun`, `BoardMessage`, `TaskDetailPayload`) and hook `useKanban(initialBoardId?: string)`:
- Uses `useSession()`, `useSettings().mutate`, and `usePolling` (every 5 s while mounted and in foreground) with a `gen` ref guard so profile switches or unmounts never write stale state.
- Actions:
  - `refresh(boardId?: string): Promise<void>`
  - `selectBoard(boardId: string): void`
  - `createBoard(title: string, description?: string): Promise<void>`
  - `saveBot(bot: Partial<BotPersona> & { name: string; role_prompt: string }): Promise<void>`
  - `deleteBot(id: string): Promise<void>`
  - `saveTask(task: Record<string, unknown>): Promise<void>`
  - `moveTask(id: string, status: TaskStatus): Promise<void>`
  - `deleteTask(id: string): Promise<void>`
  - `reviewTask(id: string, approved: boolean, feedback?: string): Promise<void>`
  - `postMessage(content: string, taskId?: string): Promise<void>`
  - `loadTaskDetail(id: string): Promise<TaskDetailPayload | null>`

### 2. `KanbanScreen.tsx`, `KanbanTaskSheet.tsx`, and `BotPersonaSheet.tsx`
- **`KanbanScreen.tsx`:**
  - Header with back button (`goBackOr(router, "/ecosystem")`), title `t("kanban.title")`, and contextual "+" button (creates a Task on the Board tab, or a Bot on the Bot tab).
  - 3 tabs (`accessibilityRole="tab"`): **Board**, **Chat**, **Bot**.
  - **Board tab:**
    - Board selector `Chips` at top (plus a "+ Board" chip opening a small `Dialog` with `TextField`).
    - Horizontal `ScrollView` of status columns (`triage`, `todo`, `ready`, `running`, `review`, `blocked`, `done`), each showing column title + count and task cards.
    - Each task card shows priority badge, title, assignee bot (`icon` + `name`), and a quick status move button or opens `KanbanTaskSheet` on tap.
  - **Chat tab:**
    - Displays `messages` for the active board (showing `author_name`, `author_type` badge, and `content`).
    - Above the input row, shows horizontal `@bot` chips (`bots.map(b => "@"+b.id)`); tapping a chip inserts `@<bot.id> ` into the message input.
    - Input + Send button calls `postMessage(text)`.
  - **Bot tab:**
    - Lists all `bots` with `icon`, `name`, `model_preset || "default"`, and 1-line `role_prompt` preview.
    - Tapping a bot opens `BotPersonaSheet` to edit; Delete `IconButton` opens a destructive confirm `Dialog` before calling `deleteBot(bot.id)`.
- **`KanbanTaskSheet.tsx`:**
  - Shows task title, description, status `Chips` (tapping a status calls `moveTask(task.id, status)`), priority `Chips`, assignee & reviewer bot selectors, workspace mode (`scratch`, `worktree`, `dir`), recurrence field, parent dependencies, artifacts list, and run history (`runs`).
  - When `task.status === "review"`, shows **Approva / Approve** (`reviewTask(id, true)`) and **Richiedi modifiche / Request changes** (with feedback input → `reviewTask(id, false, feedback)`).
  - Includes a destructive Delete button behind a confirm `Dialog`.
- **`BotPersonaSheet.tsx`:**
  - `TextField`s for `name`, `icon` (emoji), `role_prompt` (multiline system prompt), `model_preset`, and `max_concurrent` (numeric), with Save `Button` (`KeyboardAvoidingView behavior="padding"`).

## Tests (write first in `mobile/test/screens/ecosystem-kanban.test.tsx`)
1. **Board tab & task move/review:** renders columns and tasks; tapping a task in `"review"` status opens `KanbanTaskSheet`, where tapping "Request changes" with feedback calls `mutate("kanban.task.review", { id, approved: false, feedback })`, and moving status calls `mutate("kanban.task.move", { id, status })`.
2. **Create task:** opening the "+" task sheet, filling title, selecting assignee bot `"coder"`, and pressing Save calls `mutate("kanban.task.save", ...)`.
3. **Chat tab & `@bot` mention chips:** switching to the Chat tab renders board messages; tapping the `@coder` chip inserts `@coder ` into the input, and pressing Send calls `mutate("kanban.message.post", { board_id, content: "@coder build it" })`.
4. **Bot tab & persona CRUD:** switching to the Bot tab lists bot personas; creating a new bot in `BotPersonaSheet` calls `mutate("kanban.bot.save", { name, icon, role_prompt, ... })`; deleting a bot opens a confirm `Dialog` before calling `mutate("kanban.bot.delete", { id })`.
