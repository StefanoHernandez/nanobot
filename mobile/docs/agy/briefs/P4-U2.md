## Context
Logic is done; do not edit `src/ecosystem/*`. Read the hooks and their tests in `mobile/test/ecosystem/`:
- `apps.ts`:
  - `useCliApps()` returns `{ apps, loading, error, refresh, install, update, uninstall, test }`;
  - `useFeatures()` returns `{ features, requiresRestart, loading, error, … }` (these are the non-channel "plugins").
- `mcp.ts`:
  - `useMcp()` returns `{ presets, loading, error, refresh, … }`;
  - `useMcpOAuth(name)` returns `{ state: "idle"|"awaiting_user"|"polling"|"done"|"error", error, authUrl, completionInput, … }`. Read the full return.
- `common.ts`: `installGate(settings)` and `isPolicyError(e)`.

Copy the patterns from P4-U1, which is already in dev:
- `mobile/app/ecosystem/*`
- `mobile/src/screens/ecosystem/channels/*`
- the provider OAuth UI in `mobile/src/screens/settings/ProvidersPanel.tsx`, for the MCP OAuth sheet.

## What to build
1. **Enable "App"** in `mobile/app/ecosystem/index.tsx`, routing to `/ecosystem/apps`. Remove its "coming soon" state.
2. **`mobile/app/ecosystem/apps.tsx`** plus `mobile/src/screens/ecosystem/apps/*`. It has three tabs: **CLI**, **MCP**, **Plugin**.
   - **Gate banner.** When `installGate(settings).allowed` is false, show at the top: "Abilita le installazioni remote dal PC (Impostazioni → Avanzate)" / "Enable remote installs on your computer (Settings → Advanced)". Every install, update and enable button is disabled.
   - **CLI tab.** Each row shows name, version and status, with Install, Update, Uninstall and Test.
     - Install, Update and Uninstall go behind a confirm `Dialog`. The text says what is installed on the host ("Installa <name> sul computer host").
     - Uninstall uses the destructive style.
     - While a 150 s operation runs, show a spinner on that row only. On 403 (`isPolicyError`), show the gate message as a toast with no retry. On `timedOut`, show "Ancora in corso, aggiorno l'elenco" / "Still running, refreshing the list".
   - **Plugin tab.** Lists `features` with an enable/disable Switch, behind a confirm for enable. Show the restart banner when `requiresRestart` (reuse the U1 approach).
   - **MCP tab.**
     - Each row shows enabled/configured state and tools count, with an enable Switch, Test, Reconnect and Remove (destructive confirm).
     - Tapping a row opens a sheet with the preset's config fields. Secrets use `HintSecretField` with "Salvato" / "Saved" for configured values. A tools list is also in the sheet.
     - The OAuth sheet:
       - shows an "Autorizza" / "Authorize" button that opens `authUrl` via `Linking.openURL`;
       - while polling, shows a state label;
       - when `completionInput` asks for a callback URL, shows a paste field with a "Invia" / "Submit" button;
       - a cancel button.
     - **No custom-server button.** Instead, show a note at the bottom: "Aggiungi server personalizzati dalla WebUI sul PC" / "Add custom servers from the WebUI on your computer".
3. **i18n:** `apps.*`, `mcp.*` and `plugins.*` in it and en.

## Hard rules
- Never log or toast an `authUrl`, callback URL or secret.
- No `client.onChat`. Do not edit `mobile/vendor/**`, `src/ecosystem/*` or `src/settings/*`.
- Theme colors, 48 dp touch targets, safe area, KeyboardAvoidingView `behavior="padding"` in sheets with inputs.

## Tests (write first, see them fail, then implement)
`mobile/test/screens/ecosystem-apps.test.tsx`. Mock the `src/ecosystem/*` hooks.
- Gate off: the banner is visible and the Install button is disabled.
- Install opens a confirm, and confirm calls `install(name)` once.
- An install rejecting with `{status:403}` shows the policy toast.
- MCP Remove opens a confirm, and confirm calls remove once.
- OAuth with `completionInput` requiring a callback: paste plus Submit calls the complete function with the pasted text once.
- There is no "custom" or "import" button anywhere, and the note text is present.
- The Plugin switch on calls enable after confirm.
