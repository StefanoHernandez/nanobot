Read `mobile/docs/agy/README.md` first for the rules: branch, forbidden files, and the report format.

Branch: `agy/T4`, created by Claude from `dev` after T2 and T3 were merged. Before starting, run `cd mobile && npm ci`.

## Context
This is the first screen a user sees. It manages saved nanobot servers ("profiles") and tests the connection. Example: `https://myhost.example-tailnet.ts.net` with a secret.

You can use the following pieces that already exist.
- **From T2:** the UI kit in `mobile/src/ui/components` (`Button`, `TextField`, `ListItem`, `Dialog`, `toast`), plus `useTheme()` and `useT()` / i18n in `mobile/src/i18n`.
- **From T3:** `mobile/src/core/profiles.ts`. Read it. Exact API:
  - `type Profile = { id: string; name: string; baseUrl: string; hasSecret: boolean }`
  - `normalizeBaseUrl(input: string): string | null`
  - `profiles.list(): Profile[]`
  - `profiles.save(p: Omit<Profile,"hasSecret">, secret: string): Promise<void>`
  - `profiles.remove(id): Promise<void>`
  - `profiles.getSecret(id): Promise<string>`
  - `profiles.activeId()`
  - `profiles.setActive(id)`
  - `type ConnResult = {ok:true} | {ok:false; kind:"auth"|"unreachable"|"http"; message:string}`
  - `testConnection(baseUrl, secret): Promise<ConnResult>`
- **Routing:** expo-router. The route file is `mobile/app/connect.tsx`. Do not edit `mobile/app/_layout.tsx`, because Claude owns it. After success, navigate with `router.replace("/")`.
- **IDs:** generate new profile ids with `crypto.randomUUID()`. The polyfill is installed.

## What to build
**Files:**
- `mobile/app/connect.tsx`
- `mobile/src/screens/connect/ConnectScreen.tsx` (the logic lives here, so it is testable)
- `mobile/src/screens/connect/ProfileForm.tsx`
- i18n keys under `connect.*` in `it.json` and `en.json`
- Test: `mobile/test/screens/connect.test.tsx`

**Behaviour:**
- **Header:** title "Connetti a nanobot" / "Connect to nanobot".
- **Saved profiles list (`ListItem`):**
  - Title is the name, subtitle is the URL.
  - Tap: `profiles.setActive(id)` and then `router.replace("/")`.
  - Long-press opens a `Dialog`, destructive, with the message "Eliminare <nome>?" / "Delete <name>?". Confirming calls `profiles.remove(id)` and refreshes the list.
  - If the list is empty, show a short empty-state text, not a big blank area.
- **Form fields:**
  - Name. Optional; it defaults to the URL host.
  - URL, with placeholder `https://nome.tailnet.ts.net`, `autoCapitalize="none"`, URL keyboard.
  - Secret, with a show/hide toggle (`TextField` `right` slot with `IconButton`) and helper text.
    - it: "È `channels.websocket.tokenIssueSecret` in `~/.nanobot/config.json`, oppure la password del login della WebUI"
    - en: "It's `channels.websocket.tokenIssueSecret` in `~/.nanobot/config.json`, or the WebUI login password"
- **"Testa e salva" / "Test & save" button:**
  1. If `normalizeBaseUrl(url)` returns null, show a URL field error "URL non valido" / "Invalid URL". Do not call `testConnection`.
  2. While testing, the button shows `loading`. Taps during the test are ignored. Use a ref flag, not only `disabled`.
  3. Result `auth`: secret field error "Segreto richiesto o errato (serve per accessi non da localhost)" / "Secret required or wrong (needed for non-localhost access)".
  4. Result `unreachable`: URL field error "Server non raggiungibile — Tailscale attivo?" / "Server unreachable — is Tailscale on?".
  5. Result `http`: toast with `message`.
  6. Result ok: `profiles.save({id, name, baseUrl}, secret)`, then `setActive(id)`, then `router.replace("/")`.
- **Layout and safety:**
  - Respect safe-area insets (`react-native-safe-area-context`, already in Expo) and the keyboard (`KeyboardAvoidingView`). The form must scroll.
  - Never log the secret, and never show it in toasts.

## Tests (write first; they must fail before you implement)
Mock `testConnection`, `profiles`, and `expo-router`.
- Invalid URL shows "Invalid URL"/"URL non valido" and `testConnection` is not called.
- Result `{ok:false,kind:"auth"}` shows the secret error text.
- Result `{ok:true}`: a double tap on the button calls `profiles.save` exactly once, and `router.replace("/")` is called.
- Long-press on a profile, then confirm, calls `profiles.remove(id)` once.
