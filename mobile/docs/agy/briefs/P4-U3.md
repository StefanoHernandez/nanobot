## Context
Logic is done; do not edit `src/ecosystem/*`.
- `mobile/src/ecosystem/skills.ts`: `useSkills()` returns `{ skills, loading, error, refresh, discover, search, trending, detail, install, update }`. Read the signatures and `mobile/test/ecosystem/apps-skills-automations.test.ts`.
- `common.ts`: `installGate` and `isPolicyError`.
- Copy the patterns of the P4-U2 Apps screen (`mobile/app/ecosystem/apps.tsx`, `mobile/src/screens/ecosystem/apps/*`): tabs, the gate banner, confirm dialogs, the per-row spinner, and the 403/timedOut handling. Reuse its components when they fit instead of duplicating them.

## What to build
1. Enable "Skills" in `mobile/app/ecosystem/index.tsx`, routing to `/ecosystem/skills`.
2. `mobile/app/ecosystem/skills.tsx` plus `mobile/src/screens/ecosystem/skills/*`:
   - **Tabs:** Installate, Scopri, Tendenze (Installed, Discover, Trending).
   - **Search field** on top, debounced by 400 ms. While the query is non-empty, the list shows the `search(q)` results.
   - **Rows** show name, description (2 lines), source and version, plus an "aggiornamento disponibile" / "update available" chip when relevant.
     - Install and Update go behind a confirm: "Installa la skill <name> sul computer host".
     - Both are disabled when the gate is off, and the gate banner is shown.
   - **Tapping a row** opens a detail sheet that uses `detail(...)`, rendered with the existing Markdown renderer.
   - **No delete button anywhere.** Show a note in the Installed tab: "Rimuovi le skill dalla WebUI sul PC" / "Remove skills from the WebUI on your computer".
3. i18n `skills.*` in it and en.

## Hard rules
- No `client.onChat`. Do not edit `mobile/vendor/**`, `src/ecosystem/*` or `src/settings/*`.
- Theme colors, 48 dp touch targets, safe area.

## Tests (write first, see them fail, then implement)
`mobile/test/screens/ecosystem-skills.test.tsx`, mocking `useSkills`. Use jest fake timers for the debounce.
- Typing "abc" calls `search("abc")` once, only after 400 ms.
- Install opens a confirm, and confirm calls `install` once.
- Gate off: the banner is shown and Install is disabled.
- There is no element with a delete/remove label, and the note is present.
- A 403 from install shows the policy toast.
