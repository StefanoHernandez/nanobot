## Context
Claude's core is done. Read these files; do not edit them.

`mobile/src/state/usage.ts`:
- `latestContextUsage(messages)` returns `{ contextTokens, contextWindowTokens | null } | null`.
- `recentRoundUsage(messages, 8)` returns `RoundUsageRow[]`, **newest first**: `{ inputTokens, outputTokens, cachedTokens, estimated, generationMs }`.

`mobile/src/state/workspace.ts`:
- `useWorkspace(key)` returns `{ scope, info, error, browse(path, q?), setScope(scope) }`.
  - `setScope` rejects on timeout. On a server rejection it resolves and sets `error`.
  - It is off (no-op) for temporary chats.
- `withAccessMode(scope, "restricted"|"full")`.
- Types `WorkspaceScopePayload`, `WorkspacesPayload` and `WorkspaceDirectoriesPayload` are in `mobile/vendor/nanobot/webui/src/lib/types.ts` ~457-520. Read them; for example `info.controls.can_change_project` and `info.recent_projects`.

`chatsStore` and `useThreadSlice(key)`:
- `chatsStore`: `fork(key, beforeUserIndex, title?)` returns `Promise<newKey>`, and `isTemporary(key)`.
- `useThreadSlice(key)`: `forkBoundary: number | null` (a message count) and `temporary: boolean`.

`mobile/src/screens/thread/MessageList.tsx`, `MessageRow.tsx` and `ThreadScreen.tsx` are the existing thread UI.

## What to build
**Files:**
- `mobile/src/screens/thread/ContextIndicator.tsx` and `ContextPopover.tsx`
- `mobile/src/screens/thread/WorkspaceSheet.tsx`
- Fork in `MessageRow.tsx` / `MessageList.tsx`
- Small header additions in `ThreadScreen.tsx`
- i18n keys `context.*`, `workspace.*`, `fork.*` and `temporary.*` in it and en
- Test: `mobile/test/screens/context-workspace-fork.test.tsx`

**1. Context indicator and popover.**
- **Indicator:** a small ring (`View` with a border arc, or simple segmented dots; no new dependency) in the composer next to the EffortPill. It shows the % of `contextTokens / contextWindowTokens`. Hide it when the usage is null or the window is unknown.
- **Popover:** tapping the indicator opens a `Sheet` with:
  - "Contesto: 64k / 128k (50%)" / "Context: 64k / 128k (50%)";
  - one bar per round from `recentRoundUsage`, **oldest on the left** (so reverse the array), with input, output and cached stacked in theme colors, plus a legend.
  - Estimated values are marked with "~".

  Compact numbers: 1234 → "1.2k", 128000 → "128k".

**2. Workspace sheet.**
- **Header button:** an `IconButton` (`folder-outline`) in the thread header. Hide it for temporary chats or when `info?.controls?.can_change_project === false`.
- **Sheet contents:**
  - the current `scope.project_name ?? project_path`;
  - an **access mode** switch, Restricted ↔ Full. Switching calls `setScope(withAccessMode(scope, mode))`, with a loading state. On a reject or `error`, show a toast and revert the switch;
  - "Recenti" / "Recent" and "Preferiti" / "Favorites" lists from `info`. Tapping one calls `setScope({ ...scope, project_path: item.path })` (check the item shape in types);
  - "Sfoglia…" / "Browse…", which opens a simple directory browser using `browse(path)`: a list of directories, tap to go in, ".." to go up, and "Usa questa cartella" / "Use this folder" to set it.

**3. Fork.**
- Long-pressing a **finished, non-empty assistant message** opens a small menu with "Copia" / "Copy" (copy the text) and "Crea fork da qui" / "Fork from here".
- `beforeUserIndex` is the ordinal, among the user messages of the thread, of the first user message **after** that assistant message. If there is none, use the count of user messages.
- Fork calls `fork(key, idx)`, then `router.push("/chat/" + encodeURIComponent(newKey))`. On error, show a toast.
- When `forkBoundary != null`, render a divider "Fork da qui" / "Forked here" after the first `forkBoundary` messages.

**4. Temporary chat.** When `temporary` is true:
- the header shows a small "Temporanea" / "Temporary" label;
- the workspace button is hidden. The subagents badge is already hidden by Claude's gating.

## Tests (write first, see them fail, then implement)
- The indicator shows `50%` for 64000/128000, and is hidden for null usage.
- The popover renders 3 bars for 3 rounds, oldest first: the first bar's label is the oldest round's input.
- The access mode switch calls `setScope` with `access_mode: "full"`. When `setScope` rejects, a toast appears and the switch reverts.
- With messages `[user, assistant(done), user, assistant(done)]`, a fork long-press on the **first** assistant calls `fork(key, 1)` and pushes the new key.
- `forkBoundary: 2` renders the divider after 2 messages.
- A temporary chat shows the label and has no workspace button.
