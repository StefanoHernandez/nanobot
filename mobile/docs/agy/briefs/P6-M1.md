## Context
Server task `P6-S1` exposes the Hybrid Memory HTTP/WS API:
- `GET /api/ext/memory?q=<query>&status=<active|pending>&category=<cat>` → `{ facts: MemoryFact[], pending_count: number }`
- `GET /api/ext/memory/graph?entity=<name>` → `{ entities: MemoryEntity[], relations: MemoryRelation[], facts?: MemoryFact[] }`
- Mutations via `useSettings().mutate`:
  - `"memory.create"` (`{ content, category, tags }`) → `{ fact: MemoryFact, facts: MemoryFact[] }`
  - `"memory.approve"` (`{ id }`) → `{ ok: true, facts: MemoryFact[] }`
  - `"memory.delete"` (`{ id }`) → `{ ok: true, facts: MemoryFact[] }`

We want to add the **"Memoria" / "Memory"** section to the Ecosystem hub (`mobile/app/ecosystem/index.tsx` and `/ecosystem/memory`), with 3 tabs:
1. **Fatti (`active`):** searchable list of active facts/preferences/lessons, category filter chips (`all`, `fact`, `preference`, `lesson`, `project`), a **"+"** button opening a `Sheet` to add a new memory fact, and a delete action behind a destructive confirm `Dialog`.
2. **Da approvare (`pending`, with badge count):** lessons and facts extracted by the agent awaiting user approval, each with **Approva / Approve** (`memory.approve`) and **Rifiuta / Reject** (`memory.delete`).
3. **Grafo (`graph`):** entity search/filter + cards showing each entity (`name`, `kind`, `summary`) and its outgoing/incoming `relations` (`source → relation → target`); tapping a target entity pivots the graph view to that entity.

### 1. `mobile/src/ecosystem/memory.ts`
Define types and hook `useMemory()`:
```ts
export type MemoryCategory = "fact" | "preference" | "lesson" | "project";
export type MemoryRelation = { id?: string; source_entity: string; relation: string; target_entity: string; fact_id?: string };
export type MemoryEntity = { id?: string; name: string; kind: string; summary?: string };
export type MemoryFact = {
  id: string;
  content: string;
  category: MemoryCategory;
  tags?: string[];
  status: "active" | "pending";
  relations?: MemoryRelation[];
  created_at_ms: number;
  updated_at_ms?: number;
};
```
- `useMemory()` uses `useSession()` and `useSettings().mutate`, with a `gen` ref guard so stale responses after unmount or profile switch are ignored:
  - `facts: MemoryFact[]`
  - `pendingCount: number`
  - `graph: { entities: MemoryEntity[]; relations: MemoryRelation[] }`
  - `loading: boolean`
  - `error: string | null`
  - `refresh(opts?: { q?: string; category?: string }): Promise<void>`
  - `loadGraph(entity?: string): Promise<void>`
  - `create(input: { content: string; category: MemoryCategory; tags?: string[] }): Promise<void>`
  - `approve(id: string): Promise<void>`
  - `remove(id: string): Promise<void>`

### 2. `mobile/src/screens/ecosystem/memory/MemoryScreen.tsx` and `mobile/app/ecosystem/memory.tsx`
- Header with back button (`goBackOr(router, "/ecosystem")`), title `t("memory.title")`, and "+" `IconButton` (`accessibilityLabel={t("memory.add")}`) opening the create `Sheet`.
- 3 segmented tab buttons (`accessibilityRole="tab"`):
  - **Fatti / Facts** (`memory.tabs.facts`)
  - **Da approvare / Pending** (`memory.tabs.pending`, showing `(N)` when `pendingCount > 0`)
  - **Grafo / Graph** (`memory.tabs.graph`)
- **Facts tab:**
  - `TextField` search input + category `Chips` (`all`, `fact`, `preference`, `lesson`, `project`).
  - Lists `facts.filter(f => f.status === "active")` (filtered by search query and selected category).
  - Each card shows category badge, `content`, tags, linked relations if any, and a Delete `IconButton` that opens a destructive confirm `Dialog` before calling `remove(f.id)`.
- **Pending tab:**
  - Lists `facts.filter(f => f.status === "pending")`.
  - Each card has two buttons: **Approva / Approve** (calls `approve(f.id)`) and **Rifiuta / Reject** (calls `remove(f.id)`).
- **Graph tab:**
  - Calls `loadGraph(selectedEntity)` when opened or when `selectedEntity` changes.
  - Shows a filter/reset chip when `selectedEntity` is set, entities list, and relation rows (`source_entity` → `relation` → `target_entity`); tapping an entity filters the graph to that entity.
- **Create Sheet:**
  - `TextField` for `content` (multiline), `Chips` for `category` (`fact`, `preference`, `lesson`, `project`), `TextField` for comma-separated `tags`, and Save `Button` (`KeyboardAvoidingView behavior="padding"`).
- Errors map through `toastEcosystemError(e, t)` — never toast raw `e.message`.

1. Renders active facts in the Facts tab, filters by category/search, and deleting a fact opens a confirm `Dialog` before calling `mutate("memory.delete", { id })`.
