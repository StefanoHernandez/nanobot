# T2 — Theme and base UI kit (owner: agy)

Read `mobile/docs/agy/README.md` first. It sets the rules: branch, never touch `mobile/vendor/**` or `mobile/app/_layout.tsx`, the report format.

## Context
This project is "nanobot mobile", a React Native app built with Expo SDK 57 and TypeScript strict, in folder `mobile/`. It is an unofficial client for nanobot. The look must follow the **nanobot WebUI identity**, adapted to mobile.

nanobot's own design tokens are in `mobile/docs/agy/assets/nanobot-globals.css`, a copy of the nanobot WebUI `globals.css`:
- `:root` holds the light tokens and `.dark` holds the dark tokens.
- Each token is a bare HSL triplet such as `222.2 84% 4.9%`, or a `var(--x)` reference.

Existing pieces you can use:
- `mobile/src/platform/storage.ts` exports `kv` (`get/set/del`) for persistence.
- `i18next` and `react-i18next` are already installed.
- Icons: use `@expo/vector-icons`, which ships with Expo. Pick `MaterialCommunityIcons` or `Ionicons` and stay consistent.
- Do not add new dependencies without writing the reason in your report. Prefer React Native core: `Modal`, `Animated`, `Pressable`.

## What to build
**Files:**
- Create: `mobile/src/ui/theme.ts`, `mobile/src/ui/ThemeProvider.tsx`
- Create: `mobile/src/ui/components/{Button,TextField,IconButton,Sheet,Toast,ListItem,Dialog}.tsx`, plus `mobile/src/ui/components/index.ts` re-exporting all of them
- Create: `mobile/src/i18n/{index.ts,it.json,en.json}`
- Tests: `mobile/test/ui/theme.test.ts`, `mobile/test/ui/components.test.tsx`

**Interfaces. Use these exact names, because later tasks depend on them:**
- `hslToHex(triplet: string): string`, e.g. `hslToHex("222.2 84% 4.9%") === "#020817"`.
- `type Theme = { scheme: "light"|"dark"; colors: { background, foreground, card, cardForeground, popover, popoverForeground, primary, primaryForeground, secondary, secondaryForeground, muted, mutedForeground, accent, accentForeground, destructive, destructiveForeground, border, input, ring }: string /* hex */; radius: { sm: number; md: number; lg: number }; spacing: (n: number) => number /* 4*n */; font: { regular: string; medium: string; mono: string } }`
- `lightTheme`, `darkTheme`:
  - Build them by parsing the `:root` and `.dark` blocks of the CSS **at build time by hand**. Copy the triplets into `theme.ts` as constants with a comment saying where they come from. Do not parse the CSS at runtime.
  - Resolve any `var(--x)` reference to the referenced token.
- `ThemeProvider({children})` and `useTheme(): Theme`:
  - Follow the system color scheme.
  - Support an override `"system"|"light"|"dark"`, persisted in `kv` under key `ui.theme`.
  - Also export `useThemePreference(): [pref, setPref]`.
- Components, with exact props:
  - `Button({title, onPress, variant?: "primary"|"secondary"|"ghost"|"destructive", disabled?, loading?})`, default variant `primary`.
  - `TextField({label, value, onChangeText, secureTextEntry?, helper?, error?, placeholder?, autoCapitalize?, keyboardType?, right?})`. `error` replaces `helper` and turns red.
  - `IconButton({icon, onPress, accessibilityLabel, size?})`, where `icon` is an icon name. Hit area must be at least 48×48 dp.
  - `Sheet({open, onClose, title?, children})`: a bottom sheet built on `Modal`. Backdrop tap and Android back close it. It must respect safe-area insets.
  - `toast.show(message: string)`, plus `<ToastHost/>` mounted once at the root. Toasts auto-hide after 3 s.
  - `ListItem({title, subtitle?, onPress?, onLongPress?, right?, left?})`.
  - `Dialog({open, title, message?, confirmLabel, cancelLabel?, onConfirm, onCancel, destructive?, children?})`. `children` allows a text input inside.
- i18n:
  - `mobile/src/i18n/index.ts` initialises i18next. Language comes from the device locale (`expo-localization` if already installed; otherwise `Intl.DateTimeFormat().resolvedOptions().locale`). Fallback is `en`.
  - Export `i18n` and the hook `useT()` (returns `t`).
  - For now add only common keys in both `it.json` and `en.json`: `common.ok`, `common.cancel`, `common.save`, `common.delete`, `common.rename`, `common.retry`, `common.loading`, `common.error`. Later tasks add their own keys.

## Tests (write them first; they must fail before you implement)
- `hslToHex("222.2 84% 4.9%")` equals `"#020817"`, and `hslToHex("0 0% 100%")` equals `"#ffffff"`.
- `lightTheme.colors.background !== darkTheme.colors.background`.
- Every color in both themes matches `/^#[0-9a-f]{6}$/`.
- `IconButton` renders with a style whose `minHeight >= 48` and `minWidth >= 48`.
- `Dialog`: pressing confirm calls `onConfirm` once, and pressing cancel calls `onCancel`.
- `Button`: with `loading` set, pressing it does not call `onPress`.
