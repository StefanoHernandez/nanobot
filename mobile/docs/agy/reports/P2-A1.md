## Notes / deviations / decisions
- **Touch targets & UI guidelines:** All header `IconButton` buttons maintain touch targets >= 48 dp. All colors are sourced from `useTheme()`.
- **Large file threshold:** Set at 2 MB (`2 * 1024 * 1024` bytes). When `File.size > MAX_FILE_SIZE`, `File.text()` is never invoked, and the user is presented with a message and an "Open with…" button.
- **CSV table display:** Rendered with header row in bold with muted background, alternating row background colors, horizontal and vertical scrolling, capped at 500 rows with a footer indicator when truncated.

## Fix round 1

Applied fixes per `mobile/docs/agy/briefs/P2-A1-fix1.md`:
1. **CSV column widths:** Computed column widths via `clamp(maxChars(col) * 8 + 16, 80, 240)` across header and visible rows, and applied the uniform fixed width to every cell in that column. Cells ellipsize inside that width.
2. **CSV scrolling:** Replaced the nested vertical `ScrollView` inside the horizontal one with a horizontal `ScrollView` containing a single vertical `FlatList` with `stickyHeaderIndices={[0]}` and `nestedScrollEnabled`.
3. **Bottom inset:** Applied `insets.bottom` as padding to the bottom of all scroll content.
4. **`parseCsv` edge cases:**
   - Strips leading UTF-8 BOM (`\uFEFF`).
   - Drops completely empty lines.
   - Preserves final empty quoted field `""` at end of input (e.g. `a,""` -> `["a", ""]`).
   - Added unit tests covering CRLF line endings, quoted newlines, BOM, empty lines, and trailing empty quoted fields.
5. **Performance & truncation:**
   - Wrapped `prettyJson` and `parseCsv` in `useMemo` keyed on the raw file content and options.
   - For `code`, `json`, and `text` files larger than 200 KB (`200 * 1024` chars), truncated preview to 200 KB and rendered the note "Anteprima troncata — usa Apri con…" / "Preview truncated — use Open with…". Added `viewer.truncatedPreview` to Italian and English i18n dictionaries.
