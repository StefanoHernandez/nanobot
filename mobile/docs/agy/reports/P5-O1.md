## Requirements Breakdown & Implementation Citations

### 1. `mobile/src/extras/outbox.ts`
- **MMKV storage key & serialization:** Key formatted as `outbox:v1:${profileId}` storing `Record<string, OutboxItem[]>` (`mobile/src/extras/outbox.ts:25-27`, `:50-54`).
- **Cold start / profile switch paused mark:** `loadQueues(profileId)` parses JSON and maps loaded items with `paused: true` to prevent automatic flushes of stale queued items (`mobile/src/extras/outbox.ts:29-48`).
- **Live session enqueue:** `enqueue(chatKey, text, opts)` appends an item with `paused: false`, persists to MMKV, and returns the item (`mobile/src/extras/outbox.ts:71-86`).
- **Cancel item:** `cancel(chatKey, itemId)` removes the item from the chat queue and updates MMKV (`mobile/src/extras/outbox.ts:88-95`).
- **Resume item:** `resumeItem(chatKey, itemId)` clears `paused: false`, persists to MMKV, and attempts a flush if `sessionStore` is `"open"` (`mobile/src/extras/outbox.ts:97-105`).
- **FIFO flush controller (`flushNext`):** Checks all 4 guards:
  1. `sessionStore.getState().state === "open"` and `session` non-null (`mobile/src/extras/outbox.ts:109-110`).
  2. `sessionStore.getState().profile?.id === activeProfileId` (`mobile/src/extras/outbox.ts:111-112`).
  3. `slice?.loaded === true && !slice.running && !slice.uploading` (`mobile/src/extras/outbox.ts:114-116`).
  4. `head` exists and `!head.paused` (`mobile/src/extras/outbox.ts:118-120`).
  Pops `head`, persists new queue to MMKV, and dispatches `threadStore.getState().send(session, chatKey, head.text, head.opts)` (`mobile/src/extras/outbox.ts:121-129`).

### 2. `mobile/src/extras/OutboxBar.tsx`
- **Store subscriptions:** Subscribes to `sessionStore`, `threadStore`, and `outboxStore` using stable references (`mobile/src/extras/OutboxBar.tsx:17-25`).
- **Profile synchronization:** Effect calls `syncProfile(profile?.id ?? null)` on profile changes (`mobile/src/extras/OutboxBar.tsx:27-29`).
- **Auto-flush trigger:** Effect triggers `flushNext(chatKey)` when connection is open, slice is loaded and idle, and unpaused item is queued (`mobile/src/extras/OutboxBar.tsx:31-35`).
- **Empty state:** Returns `null` when `queue.length === 0` (`mobile/src/extras/OutboxBar.tsx:37-39`).
- **Item row & badges:** Renders badge with `t("outbox.pending")` or `t("outbox.paused")` (`mobile/src/extras/OutboxBar.tsx:63-65`).
- **Actions:**
  - Send now button rendered when `item.paused && state === "open"` (`mobile/src/extras/OutboxBar.tsx:75-81`).
  - Cancel button with $\ge 48$ dp touch target (`mobile/src/extras/OutboxBar.tsx:82-88`, `styles.iconBtn: minWidth: 48, minHeight: 48`).
- **Styling:** Strict theme tokens via `useTheme()` (`mobile/src/extras/OutboxBar.tsx:42-108`).
