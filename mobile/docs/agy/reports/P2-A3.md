## Notes / deviations / decisions
- **Theme success token:** In accordance with the brief instructions ("If the theme has no green, add `success` to the theme the same way the other tokens are defined, and say so in the report"), `success` was added to `Theme` with HSL definitions for light and dark schemes. All diff additions and `+added` indicators use `th.colors.success`.
- **Deduplication in ActivityRow:** `fileEdits` are collected into a `Map<string, UIFileEdit>` keyed on `call_id` so that repeated updates to the same tool call preserve the latest state.
- **Image collection:** `collectThreadImages` extracts image attachments from both `m.media` (filtering by `classify(item) === "image"`) and `m.images`, deduplicating by resolved absolute URL while preserving message order.
