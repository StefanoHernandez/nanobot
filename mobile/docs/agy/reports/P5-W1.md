## Requirements Breakdown & Implementation Citations

### 1. `mobile/plugins/withNanobotWidget.js`
- **CommonJS Expo config plugin:** Implemented using `@expo/config-plugins` (`withAndroidManifest`, `withDangerousMod`) (`mobile/plugins/withNanobotWidget.js:1-5`).
- **DangerousMod generation during prebuild:**
  - Generates `res/layout/nanobot_widget.xml`: LinearLayout with title, status TextView, and "New Chat" tap button (`mobile/plugins/withNanobotWidget.js:15-39`).
  - Generates `res/xml/nanobot_widget_info.xml`: AppWidgetProviderInfo XML metadata (`mobile/plugins/withNanobotWidget.js:41-53`).
  - Generates `NanobotWidgetProvider.kt`: AppWidgetProvider in package `dev.nanobot.mobile` reading `SharedPreferences` (`nanobot_widget_prefs`), updating RemoteViews text, and attaching `FLAG_IMMUTABLE | FLAG_UPDATE_CURRENT` PendingIntent launching `nanobot://new-chat` (`mobile/plugins/withNanobotWidget.js:55-103`).
  - Generates `NanobotTileService.kt`: TileService for Quick Settings tile handling Android 14+ PendingIntent requirements (`Build.VERSION.SDK_INT >= Build.VERSION_CODES.UPSIDE_DOWN_CAKE` via `startActivityAndCollapse` PendingIntent) and launching `nanobot://new-chat` with `FLAG_ACTIVITY_NEW_TASK` (`mobile/plugins/withNanobotWidget.js:105-146`).
- **AndroidManifest idempotent injection (`modifyAndroidManifest`):**
  - Injects `<receiver android:name=".NanobotWidgetProvider" android:exported="true">` with intent-filter and meta-data (`mobile/plugins/withNanobotWidget.js:161-182`).
  - Injects `<service android:name=".NanobotTileService" android:exported="true" android:permission="android.permission.BIND_QUICK_SETTINGS_TILE">` (`mobile/plugins/withNanobotWidget.js:184-201`).
  - Verified idempotent across repeated calls (`mobile/plugins/withNanobotWidget.js:153-158`, `mobile/test/extras/widget.test.tsx:82-108`).
- **Plugin registration:** Added `"./plugins/withNanobotWidget"` to `plugins` array in `mobile/app.json:49`.

### 2. `mobile/src/extras/widget.ts` & `mobile/app/new-chat.tsx`
- **Sanitized status sync (`syncWidgetStatus`):**
  - Defines `WidgetStatus` type (`mobile/src/extras/widget.ts:6-10`).
  - Maps internal states (`toWidgetState`) to `"open" | "connecting" | "offline" | "none"` (`mobile/src/extras/widget.ts:12-21`).
  - Writes snapshot to `kv` key `"widget.status"`, never persisting `baseUrl`, tokens, or credentials (`mobile/src/extras/widget.ts:27-32`).
  - Invokes `NativeModules.NanobotWidget?.updateStatus` in a safe `try/catch` guard (`mobile/src/extras/widget.ts:34-38`).
  - `startWidgetStatusSync` subscribes to `sessionStore` changes and returns cleanup function (`mobile/src/extras/widget.ts:40-47`).
- **Deep link handler (`handleNewChatIntent`):**
  - Checks `profiles.activeId()`: replaces to `"/connect"` if null (`mobile/src/extras/widget.ts:53-56`).
  - When `state === "open"`: awaits `chatsStore.getState().newChat()` and navigates to `router.replace(chatPath(key))` (`mobile/src/extras/widget.ts:58-64`).
- **Route component (`mobile/app/new-chat.tsx`):**
  - Renders themed container with `ActivityIndicator` and `t("widget.openingNewChat")` (`mobile/app/new-chat.tsx:39-44`).
  - Effect verifies `profiles.activeId()`, calling `router.replace("/connect")` if missing (`mobile/app/new-chat.tsx:18-21`).
  - When `state === "open"`, invokes `handleNewChatIntent()` once guarded by `handledRef` (`mobile/app/new-chat.tsx:23-28`).
  - When `state === "offline"` or `"auth_error"`, falls back to `router.replace("/")` (`mobile/app/new-chat.tsx:29-33`).
