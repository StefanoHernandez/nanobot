## fix1

### Addressed issues
1. **Critical:** In `McpOAuthSheet.tsx`, added "Start authorization" / "Avvia autorizzazione" button calling `oauth.start()` with loading state when in `idle` state and without `authUrl`.
2. **Important:** Callback URL paste field is now shown strictly when `oauth.completionInput === "callback_url"` (no paste field for `device_code`).
3. **Important:** Double-submission prevented with `submittingRef` guard and `submitted` state, input is disabled during submission and cleared on success.
4. **Important:** In `McpTab.tsx` and `McpSheet.tsx`, MCP enable now respects `gateAllowed` (disabled when gate is off) and requires confirm dialog ("Attiva il server MCP <name> sul computer host" / "Enable MCP server <name> on host computer").
5. **Minor:** `oauth.error` mapped to fixed localized string (`mcp.oauthError`), never rendering raw server error strings.
6. **Minor:** `McpSheet.tsx` `handleSave` now catches and displays error toasts (including policy toast on 403).
7. **Minor:** Replaced `Platform.OS === "ios" ? "padding" : "padding"` with `"padding"`.
8. **Minor:** In `CliAppsTab.tsx`, `handleTest` now shows a success toast on successful test execution.
9. **Minor:** In `AppsScreen.tsx`, tabs configured with `accessibilityRole="tab"` and `accessibilityState={{ selected }}`. `Button` and `TextField` updated to pass through accessibility and `editable` props.
