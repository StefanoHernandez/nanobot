## Notes / deviations / decisions
- **Touch targets & UI:** `MentionMenu` item rows have a minimum height of 48 dp. All styling adheres to semantic theme colors (`useTheme`).
- **Session safety:** Guarded `session.get` calls with `typeof session.get === "function"` so consumers/tests mounting without full mock session methods do not encounter runtime errors.
- **Deduplication:** Deduped session mentions by `session_key`, CLI apps by `name`, and MCP presets by `name`. Pruned all picked mentions reactively whenever text is changed.
