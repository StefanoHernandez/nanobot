## Security & Design Notes
- **Secrets & Credentials:** Never logged, toasted, or placed into constructed URLs. Untouched secrets are completely omitted from the configure payload; clearing secrets is protected by a destructive confirmation Dialog and passes `null`.
- **Pairing Approvals:** Approve requests are protected behind a confirmation Dialog ("Grants this sender access to the agent"). Deny directly rejects the code.
- **Connect Flow:** Evaluates `supportsConnect` (feishu, linear, whatsapp, weixin, lark, or `capabilities.includes("connect")`). While waiting, renders QR code with `QRCode` from `react-native-qrcode-svg`, provides link opening via `Linking.openURL`, cancel button, and weixin verification code input. Handles `done`, `expired`, and `error` states.
- **UI Guidelines:** Touch targets $\ge 48$ dp, semantic colors via `useTheme()`, `KeyboardAvoidingView` with `behavior="padding"` in sheets, pull-to-refresh on channels list, and restart banner bound to `useRestart()`.
