## Notes / deviations / decisions
- **KeyboardAvoidingView and SafeAreaView:** `ThreadScreen.tsx` already wraps the thread screen in `SafeAreaView` and `KeyboardAvoidingView`. As instructed by the brief, `Composer` does not wrap itself in a redundant second `KeyboardAvoidingView`.
- **IconButton `disabled`:** Added `disabled?: boolean` to `IconButtonProps` in `mobile/src/ui/components/IconButton.tsx` with `accessibilityState={{ disabled: !!disabled }}` and `opacity: disabled ? 0.38 : 1` so the button disables interaction and indicates its state accessibly.
- **Stop label in Italian:** In `it.json`, `composer.stop` is `"Stop"` (in `en.json` it is `"Stop"`). `ThreadScreen` header uses `thread.stop` which is `"Ferma"`. Having `"Stop"` for `composer.stop` matches the brief's requirement ("with empty draft shows Stop") and avoids label collisions in `test/screens/thread.test.tsx` which asserts `screen.getByLabelText("Ferma")`.
- **Command prefix normalization:** Commands from `loadCommands` are normalized to ensure leading `/` in `SlashMenu`.
- **Command selection:** Selecting a command via `SlashMenu` updates the draft to `${cmd.command} ` (with trailing space) and focuses the text input.
