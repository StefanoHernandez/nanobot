## Doubts / deviations
- Dialog title is a new key `connect.deleteTitle` ("Delete server"/"Elimina server"), distinct from the confirm button "Delete", so the test can find the button by text.
- Double-tap test: RNTL v14 `fireEvent.press` awaits the async `onPress`, so two taps overlap `act()` calls (console errors) or hang on a pending promise. The test therefore calls the host element's `onClick` twice inside one `act`. It proves `save` is called once, but note that the `Button` is also `disabled` while `loading`; the `busy` ref is the guard that does not depend on that.
- Name defaults to the URL host when empty (`new URL(baseUrl).host`).
- The secret is never logged or passed to toasts; the `http` result toasts only `r.message` from `testConnection`.

## Fix round 1

Brief: `mobile/docs/agy/briefs/T4-fix1.md`.

### Changes
- `ConnectScreen.tsx`: `submit` now has a `catch` that shows only `toast.show(t("common.error"))` (never the error text); `finally` kept. If a saved profile has the same normalized `baseUrl`, its id (and name, when the name field is empty) is reused. An empty secret field with an existing `hasSecret` profile uses `await profiles.getSecret(id)` for both `testConnection` and `profiles.save`, so the stored secret is not deleted. `getSecret` is inside the `try`, so its failures also get the generic toast.
- `ProfileForm.tsx`: `autoCorrect={false}`, `spellCheck={false}`, `autoComplete="off"` on the URL and secret fields.
- `ui/components/TextField.tsx` (T2 file): minimal pass-through of `autoCorrect | spellCheck | autoComplete` to `TextInput`.
- `test/screens/connect.test.tsx`: mock `normalizeBaseUrl` now strips trailing slashes, mock `profiles.getSecret` added, two new tests.
