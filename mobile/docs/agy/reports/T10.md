## Notes / deviations / decisions
- **Conditional rendering of modal sheets:** `<Sheet>` calls `useSafeAreaInsets()`. In tests that do not mount a `<SafeAreaProvider>` around the full screen (e.g. `thread.test.tsx`), rendering `<Sheet>` while closed causes `useSafeAreaInsets` to throw. Conditionally rendering `<Sheet>` only when `open` in `CommandDrawer.tsx`, `StatusDot.tsx`, and `EffortPill.tsx` keeps closed sheets completely unmounted and clean.
- **Immediate ref flag for single-flight Apply:** In `EffortSheet.tsx`, a `busyRef` and `selectedRef` pair prevents race conditions where double-tapping "Apply" rapidly could dispatch multiple API calls before React batched state updates flush.
- **Status colors:** The hex literals `#22c55e` (green) and `#eab308` (yellow) are strictly confined to the exported `STATUS_COLORS` constant in `StatusDot.tsx`. All other colors use `useTheme()`.
