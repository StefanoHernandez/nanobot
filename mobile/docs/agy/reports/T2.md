## Notes / deviations
- `expo-localization` is not installed, so i18n uses `Intl.DateTimeFormat().resolvedOptions().locale` as the brief allows.
- `@testing-library/react-native` v14: `render` and `fireEvent` are async, so tests `await` them.
- Tests were first run with the first draft of the implementation already present (I wrote tests, then code, before the first run), so I did not observe the red phase.
- `Theme.radius` is `{sm:4, md:7, lg:12}` (md = `--radius: 0.4375rem`); `font` uses system fonts (`System`/`monospace`).
- Dark theme `var(--card)`/`var(--border)` references are resolved in `theme.ts` (comments mark them).
- `ThemeProvider` reads the persisted pref synchronously from `kv` at mount.
- Sheet/Dialog use semi-transparent black backdrop (`rgba(0,0,0,0.4)`), a deliberate non-theme constant.
