## Notes / deviations / decisions
- **Touch targets & UI guidelines:** AttachmentBar chip remove buttons have minWidth and minHeight set to 48 dp. All colors are sourced from `useTheme()`.
- **Loading on send button:** Added a `loading?: boolean` prop to `IconButton` which renders an `ActivityIndicator` and marks the button disabled and busy, keeping touch targets >= 48 dp and preserving the accessible label.
- **`Sheet` guard:** Added `if (!open) return null;` in `Sheet` and conditionally mounted `<Sheet>` in `Composer` so consumers running tests outside a `SafeAreaProvider` do not trigger unhandled insets errors when the sheet is closed.
